App Name: Todo Manager

Description: The Todo Manager was created to function as virtual checklist used to manage daily tasks and to promote productivity. The Todo Manager allows users to create, edit, complete, and organize their daily tasks. The application includes user authentication, filtering and sorting options, profile statistics, and responsive styling for desktop and mobile devices and uses the power of React & Vite.

The project was developed as part of the Code the Dream React curriculum and demonstrates modern React development practices including hooks, context, reducers, routing, form validation, input sanitization, and API integration.

Features: + User authentication (login/logout) + Create new todos + Edit existing todos + Mark todos as complete or incomplete + Delete todos + Filter todos by status + Searching todos + Sort todos by different criteria + Profile page with task completion statistics + Completion percentage tracking + Responsive design for desktop and mobile devices + Client-side form validation + Input sanitization using DOMPurify + Protected routes for authenticated users

Design Decisions:

The application uses a clean and minimal interface with custom styling implemented through CSS Modules.

Design choices include:

- Black login page to create contrast and focus user attention on authentication.
- Notebook-inspired task management page to reinforce the productivity theme.
- Syne font for headings to create visual hierarchy.
- Inter font for body text to improve readability.
- DotGothic16 font for loading states to provide visual distinction.
- Responsive layouts that adapt to desktop and mobile screens.
